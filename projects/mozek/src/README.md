# Mozek Angular Library (src)

This directory contains the source SCSS and component library for **Mozek Angular**.

## Getting Started

1. **Install the package** (already done in the main project).
2. **Import components** from the public API as needed.
3. **Add global styles** – include Mozek's style tokens in your global stylesheet:

```scss
@use "mozek-angular/src/styles" as moz;
```

Feel free to customize the theme variables defined in `_tokens.scss` and `_utilities.scss` to match your brand.
